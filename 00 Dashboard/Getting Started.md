# 开始使用

## 第一次打开

1. 在 Obsidian 设置中确认核心插件 **Bases、Properties、Templates、Daily notes、Backlinks** 已启用。
2. 打开 [[00 Dashboard/Research OS|Research OS]] 并设为书签。
3. 复制 [[90 Templates/Project|项目模板]] 创建你的第一个真实项目。
4. 复制 [[90 Templates/Research Question|研究问题模板]] 定义第一个问题。
5. 复制 [[90 Templates/Literature|文献模板]] 添加文献。

## 最小可用工作流

```text
收集文献
→ 快速筛选
→ 加入阅读队列
→ 完成阅读笔记
→ 提取证据
→ 链接研究问题
→ 加入综合笔记或写作章节
```

## 建议先保留的状态值

### 文献

`inbox` → `to-screen` → `to-read` → `reading` → `read` → `annotated` → `synthesized` → `cited`

### 项目

`planning`、`active`、`paused`、`completed`、`archived`

### 研究问题

`exploring`、`testing`、`supported`、`challenged`、`resolved`

### 写作章节

`outline`、`drafting`、`revising`、`ready`
