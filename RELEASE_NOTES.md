# Research OS v0.6.0-beta.2

## Highlights

- Ask your library with citations linked to retrieved evidence.
- Hybrid keyword and semantic retrieval.
- Windows x64 local Research OS Engine.
- BYOK embedding and chat provider configuration.
- Automatic indexing for new papers and batch preparation for existing libraries.

## Known limitations

- Beta release; keep backups of important Vault data.
- Windows x64 Engine only; no macOS or Linux Engine artifact yet.
- The Engine is unsigned; Windows may identify it as an unknown publisher.
- AI features use user-provided remote AI APIs.
- No Obsidian Community Plugins marketplace installation yet.
- The Engine is not downloaded or started automatically.
- `grounded: true` validates the citation contract, not full claim entailment.
- No reranker or Agent.
- PDF evidence sentence highlighting is not implemented.
